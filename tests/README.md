# tests/ —— 自测

这个目录放**所有测试**，仓库根只留可交付的源码（`mdview.py`）与文档。
所有脚本都从自身位置推出仓库根，因此**在任何目录下执行都可以**。

| 文件 | 作用 | 命令 |
|------|------|------|
| `tests_render.py` | 渲染器回归测试（199 项，纯 `unittest`，不联网不起服务） | `python3 tests/tests_render.py` |
| `selftest.sh` | 端到端 HTTP 冒烟测试（345 项断言，自己起临时服务、跑完自清理） | `bash tests/selftest.sh` |

## 一套跑完

```bash
# 在仓库根执行
python3 tests/tests_render.py      # 199 项单元测试
bash tests/selftest.sh             # 345 项端到端断言
```

两个命令都是零依赖、可重复执行的，不需要 `pip install`。

## 各自覆盖什么

**`tests_render.py`** —— 纯渲染层，不起服务：
源码/配置类扩展名必须判为文本（含 `.ts` 不能被误判成视频）、无扩展名的
`Makefile`/`Dockerfile`/`.gitignore` 也要按文本发、二进制类型不受影响；
强调 flanking 规则（中文/词内/三连/相邻/未配对）、转义与行内码混排的占位符泄漏、
代码块内 HTML 必须转义（XSS 回归）、Dockerfile/Compose 指令大小写、数字边界
（`C.UTF-8`、`v1.2.3` 不被切）、无语言围栏必须素色、链接与图片重写、路径夹紧、
**目标路径的编码规则**（`%20`/`%2520`/`%23`/`%3F` 只解一次编一次、`<>` 目标、裸空格
退化成字面文本、链接与图片同一目标必须逐字节相同、引用式图片三种写法 + 协议被拒）、
列表嵌套与松紧、表格对齐、搜索文件名命中；
**标签渲染的两类消费方**（alt 必须是纯文本 + 引号转义、标签里的裸 HTML 保持转义、
引用式产出的标记必须 stash 成 token 不被后处理再解析）；
**图片放大**（行内式/引用式都包 `<a class="zoom">`、href 与 src 逐字节同源、
徽章不嵌套、行内码与围栏块不包裹）；等等。

**`selftest.sh`** —— 真起服务、真发 HTTP：
代码块的复制按钮必须由 JS 注入（HTML 里不能有硬编码的死按钮）；
搜索跳转的落点必须竖向居中、且对非 L 锚点不生效；
**图片放大**的服务端一半（包裹形态、href 与 src 同源、脚本与样式已内联、
基线正文里没有写死的 `<dialog>`、示例页的 1600×900 大图也包了链接且尺寸字节正确）；

docs/preview 下每个样例都要可访问、图片魔数正确；
**裸 URL 自动链接**（临时 `bare.md` 真往返，加上示例页 `index.md` 的「裸 URL 自动链接」
小节逐条断言：可点、查询串只转义一次、括号配平、全角句末标点归句子、中文 URL 保留、
行内码与围栏块内不链接化、标签里不嵌套 `<a>`）；
目录索引、渲染结果、`?raw=1` 源码视图的行锚点（并核对第 5 行内容与源文件一致）、
子目录与图片相对路径、301 补斜杠、深度树、全文搜索分栏、断链检查（页面里每个
根相对 `href`/`src` 逐个请求）、路径穿越不外泄、以及 `--safe` / `--no-search` /
端口占用回退三个参数开关。结束时打印 `PASS=n FAIL=n`，非零退出码表示有失败项。

可用 `PORT=9000 bash tests/selftest.sh` 换一组临时端口（脚本会用到 PORT..PORT+5）。

## 约定

- 新增测试请放在本目录；不要往仓库根加脚本。
- `tests_render.py` 里的断言若与实现冲突，**先核对规格**再改断言 —— 历史上出现过
  "断言写错、实现被逼着迁就"的情况（见 `../SELFTEST.md` §4）。
- 改动 `mdview.py` 后请跑：`tests_render.py` → `selftest.sh`。定位代码用 section 标识搜索（如 `SECTION 5`），不依赖行号。
