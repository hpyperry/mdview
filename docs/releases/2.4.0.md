# mdview 2.4.0

**发布日期**：2026-11-07

2.4.0 重做了主岛布局、页面身份区与搜索：内容岛铺满并固定，正文在岛内滚动；
文档/源码/目录的页面身份与操作迁入全局顶栏；搜索改为分批扫描和渐进追加。
CLI 参数、Trust/CSP 边界、编码检测、压缩包范围与配置格式保持不变，运行时仍然
零外部请求。

## 新增：全宽固定主岛与 TOC 分栏

- 内容岛铺满 `.app` 并与顶栏左右对齐，阅读行上限提升到 1200px；
- 桌面端顶栏与主岛固定，正文、目录、源码和搜索结果都在岛内滚动；移动端保留普通
  页面滚动；
- ≥1280px 的 Markdown 页为“正文岛 1fr + 24px 间距 + TOC 岛
  `clamp(160px, 13vw, 240px)`”，正文岛只收右边缘，播放约 240ms 分栏动画；
- 1100–1279px 保留 24px 细轨，悬停显示单条标题；<1100px 回到正文顶部内联目录；
- TOC 岛目录项少时，“回到顶部”固定在岛底部；
- 顶栏、主岛、TOC 岛间距统一为 24px；主岛只拦截纵向滚动，横向双指滑动仍可
  前进/后退。

决策记录：[ADR 0028](../architecture/adr/0028-full-width-shell-and-toc-split.md) ·
[ADR 0029](../architecture/adr/0029-fixed-island-inner-scroll.md)。

## 变更：页面身份与操作迁入顶栏

- 去掉产品 logo；
- 文档/源码/目录页顶栏从左到右：导航按钮、面包屑路径、居中的文件名（22px）与
  第二行元信息，右侧点状操作菜单、搜索、主题；
- 四个操作（源码/下载/导出图片/导出 PDF）收进 142px 二级菜单；菜单按钮与搜索/
  主题一样默认只显示图标，悬停显示用途；
- 新增 `actions` 岛处理菜单开合、Esc/外部点击关闭与 `aria-expanded`；
- 导出图片时菜单保持打开，完成后显示绿色对勾；下载反馈窗口 500ms；
- 搜索页是例外，仍保留内容面页头和搜索表单；
- 源码页移除下载按钮，只保留预览；`?download=1` 仍可直接下载。

决策记录：[ADR 0032](../architecture/adr/0032-topbar-page-context.md)
（取代 ADR 0031）。

## 新增：渐进搜索

- 每批最多扫描 2000 个文件、约 1.2 秒，返回 40 个文件组 / 200 条结果；
- 单文件最多 5 条命中；
- 结果底部显示已扫描文件数和「继续搜索」；有 JS 时追加结果并更新计数，无 JS 时
  导航到下一批 `cursor` 页面；
- `WalkDir` 固定排序，cursor 续扫不重复；超大目录不再一次扫完整棵树。

决策记录：[ADR 0030](../architecture/adr/0030-progressive-search-batches.md)。

## HTML 第二 origin

未信任根的独立 HTML 不再使用 `sandbox` iframe，改为 302 到 HTML 第二 origin 的
只读静态镜像（默认主端口 + 1，`--html-port` 可覆盖）。module、sessionStorage、
Service Worker、同源 fetch 与真实 MIME 恢复正常；主 origin 不直出未信任 HTML。
移除沙箱外壳与 `?view=1` 裸页；`?raw=1` 与 `?download=1` 不变。

## 修复

- Markdown 分栏动画在 Chrome 157 上结束后 `animationName` 会清空，测试改为读取
  稳定的 `body[data-split]` 状态；
- 源码页不再提供无必要的下载按钮；
- 导出图片成功后不再显示“图片已生成”“图片已导出”等右侧状态文案，只保留图标与
  禁用反馈；错误提示仍保留。

## 兼容性与升级

- 支持 Chromium 88+；运行时零网络请求不变；
- CLI、Trust 配置、CSP、编码检测、压缩包范围不变；
- 内容默认宽度、主岛滚动方式和页面身份位置发生变化；使用 `?raw=1`/`?download=1`
  的脚本不受影响；
- 搜索 URL 新增可选 `cursor` 参数，旧搜索链接仍可用。
