# mdview 2.6.0

**发布日期**：2026-11-11

2.6.0 是布局、资源加载与交互修复版本：宽屏外壳铺满视口，Markdown 主岛为目录岛
让位并把正文居中；高亮包按需加载、文本响应压缩；新增品牌标记与 favicon；默认只
监听本机。

## 布局：外壳铺满，主岛让位，正文居中

- `.app` 去掉 1680px 上限，顶栏与主岛在所有页面类型上铺满视口；
- ≥1280px 的 Markdown 页主岛左边缘不动，右边缘只向左让出“目录岛宽度 + 32px”；
- 目录岛作为右侧独立面板，与顶栏右边缘对齐，中间露出 32px 页面底色；
- 正文在主岛内居中，主岛、工具栏、面包屑和目录岛的位置不因正文居中而移动；
- 1100–1279px 保留 24px 目录细轨，<1100px 回到正文顶部内联目录；
- 搜索页页头与结果同步限宽；源码/目录/搜索页仍铺满。

决策见 [ADR 0036](../architecture/adr/0036-wide-content-group.md)，验收见
[F-50](../reference/features.md) 与
[宽屏布局测试报告](../testing/reports/browser-report-2026-11-11-wide-layout.md)。

## 性能：按需加载高亮，文本压缩

- highlight.js / highlight.css 只在源码页与含代码的 Markdown 页加载；目录、搜索、
  无代码文档不再下载约 1 MB 的高亮包；
- HTML/CSS/JS 启用 gzip/brotli，图片与压缩包保持原字节；
- VS Code 的 `markdown.css` / `highlight.css` 在构建时 minify，仍保持独立文件；
- 清理旧侧栏/三列外壳 CSS，补 `meta description`。

## 品牌标记与 favicon

- 顶栏最左新增 24×24 蓝色圆角方块 + 白色 Markdown “M”，点击回到首页；文件名仍
  居中；
- 新增 `/_assets/favicon.svg` 与 `/_assets/favicon.png`（32×32）两条嵌入资产，
  支持 SVG 的浏览器优先用 SVG；
- 不预留 `/favicon.ico`，保持内部 URL 标记与真实文件优先的规则。

见 [ADR 0037](../architecture/adr/0037-brand-mark-and-favicon.md)。

## 交互修复

- **滚动回弹**：主岛纵向关闭弹性回弹（`overscroll-behavior-y: none`），横向仍
  放行浏览器后退/前进手势；
- **面包屑返回**：文件预览的面包屑保持普通目录 URL，点面包屑或浏览器后退回到
  目录时定位到来源文件行并短暂高亮，URL 不写文件名；
- **复制兜底**：`navigator.clipboard.writeText` 被拒或不可用时回退
  `document.execCommand('copy')`；文件复制失败在页面底部显示提示；
- **图片放大兜底**：不支持 `<dialog>.showModal` 的浏览器不再拦截点击，图片按普通
  链接打开原图。

## 变更

- 默认监听地址从 `0.0.0.0` 改为 `127.0.0.1`，默认只监听本机；局域网访问需显式
  `--host 0.0.0.0`。
- 顶栏最左增加首页 logo；搜索页页头与结果限宽到正文组宽度。

## 测试

- 101 单元 + 137 渲染兼容 + 27 golden；黑盒 HTTP 309；TTY 9；浏览器探针 367；
  源码页性能 4；artifact 冒烟 7；`bash tests/run-all.sh` 全绿。
- 新增 ADR 0036–0038，以及宽屏布局、纵向回弹、面包屑返回、能力兜底、品牌/favicon、
  资源加载与压缩的夹具、测试报告和截图证据。

## 已知限制

- 使用手册单页包含 17 张 1440×900 PNG（约 1.2 MB），移动 Lighthouse 仍以这页最重；
- HTML 与 `/_nav` 使用 `Cache-Control: no-store`，bfcache 仍被禁用；这是“本地改完
  立刻看到”的取舍；
- `app.js` / `highlight.js` 不含 source map；
- 仍有 3 个 CSS 请求（vendor CSS 按 ADR 0012 保持独立），压缩后已明显减小；
- 旧版 Chromium 88 之外的浏览器（Safari/Firefox）未逐项实机验收 `<dialog>`、图片
  格式与 bfcache 行为。
