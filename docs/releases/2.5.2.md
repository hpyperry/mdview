# mdview 2.5.2

**发布日期**：2026-11-07

2.5.2 是文档版本：新增面向使用者的功能手册与截图，把 README 精简为项目入口，
并记录可视化验收发现的问题。运行时行为与 2.5.1 一致。

## 新增：使用手册

- `docs/manual/README.md` 覆盖目录、Markdown、查找/复制、源码页、搜索、导航、
  主题、导出、HTML 与第二 origin、Trust、压缩包、文件夹下载、编码、图片、错误页
  与无 JS；
- 每个功能给出操作步骤与截图，共 17 张，放在 `docs/manual/images/`；
- 新用户可以从 README 的能力列表直接跳到手册。

## 变更：README

- 只保留项目简介与能力、手动编译/运行方式、License；
- 测试、架构、路由、边界与决策不再放在 README，改由 `docs/` 承载。

## 记录

- `docs/manual/testing-issues-2026-11-07.md` 记录本轮 browser-use/headless 验收
  发现的问题：功能矩阵与版本文案过期、复制失败提示依赖 hover、超大根目录搜索
  首批可能看不到目标文件等；本轮按要求不修改。

测试与截图：`docs/manual/README.md`；问题清单：
`docs/manual/testing-issues-2026-11-07.md`。
