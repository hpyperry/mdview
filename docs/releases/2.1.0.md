# mdview 2.1.0

**发布日期**：2026-10-27

2.1.0 收敛与 Python 静态服务器访问文件的差异：文件尾斜杠、Markdown 扩展名口径、
内部 URL 与真实文件同名冲突，以及 `--safe` 的帮助文本与搜索边界。

## 变更

- **内部 URL 查询参数消歧**：搜索页、导航 JSON、内嵌资产分别使用
  `/search?__mdview=search`、`/_nav?__mdview=nav`、
  `/_assets/<name>?__mdview=asset`。不带标记的同路径按普通文件处理：同名文件/
  目录优先，缺失即 404。根目录有名为 `search`、`_nav` 或 `_assets/` 的文件时，
  内部功能仍可用，真实文件也能通过自然 URL 打开。
- **Markdown 扩展名口径**：`.md`/`.markdown` 渲染为文档页并进入 Doc 内容搜索；
  `.mdx` 保持源码页，导航和语言标签改称 MDX。大小写不敏感。
- **目录非目标**：目录始终列目录，不自动寻找 `index.html`/`index.htm`；需要首页
  时直接访问 `/index.html`。

## 破坏性变更

- 旧的不带 `__mdview` 标记的 `/search`、`/_nav`、`/_assets/*` 不再作为内部别名。
  旧搜索书签、旧导航请求和旧缓存页面里的资产请求会失效；升级后刷新页面即可。
- 搜索表单改用隐藏字段承载 `__mdview=search`，因为 GET 表单会替换 action 的
  查询串。

## 修复

- **文件尾斜杠**：`/b.txt/`、`/b.txt%2f`、`/a.zip/docs/x.md/` 返回 404；目录缺
  尾斜杠仍是 301。与 Python 静态服务器和压缩包条目行为一致。
- **`--safe` 文案与搜索**：帮助文本改为“只放行 `.md`/`.markdown`、图片与 HTML
  源码；HTML 只给源码”；搜索也只覆盖放行类型，不再返回被 404 的文本/压缩包文件名
  与正文片段。
- **`--safe` 放行 `.markdown`**：与新的 Markdown 扩展名口径一致；`.mdx` 仍拦截。
