# mdview 2.5.0

**发布日期**：2026-11-07

2.5.0 重排了页面身份的层次：顶栏只保留导航、居中文件名与全局搜索/主题；面包屑
移入顶栏与主岛之间的缝隙；文件信息与操作固定在主岛顶部。文件页新增查找与复制，
目录页支持文件夹打包下载与居中留白，高亮主题切到 VS Code Light+/Dark+。
CLI 参数、Trust/CSP 边界、编码检测、压缩包范围与配置格式保持不变，运行时仍然
零外部请求。

关联：Issue [#74](https://github.com/hpyperry/mdview/issues/74)；PR [#75](https://github.com/hpyperry/mdview/pull/75)。

## 新增：文件查找与复制

- 文档页和源码页主岛功能区新增「搜索」「复制」，顺序为
  「搜索 复制 下载 其余」；
- 查找浮层显示 `当前/总数`，支持上一个/下一个、`Enter` / `Shift+Enter`、`Esc`；
  匹配跳过行号栏、代码标题条与复制按钮；
- 复制通过 `?download=1` 取回原始全文，成功/失败都有图标与浮层反馈。

## 新增：文件夹打包下载

- 目录页的文件夹行新增打包下载；压缩期间显示全屏等待遮罩；
- zip 写入系统临时目录，下载结束或客户端中断后删除；
- `prepare` 一次性 token 绑定目录路径，10 分钟过期、单次使用；
- 跳过软链接与特殊文件；`--safe` 和未信任根不显示入口并拒绝请求。

## 变更：页面身份与主岛功能区

- 顶栏：导航、居中文件名、全局搜索、主题；搜索改名「全局搜索」；
- 缝隙：左对齐 sticky 面包屑，换行时自然增高；
- 主岛顶部：左侧操作、右侧文件信息；窄屏先收起操作到「更多」，再隐藏信息；
- 操作默认图标化，hover/聚焦显示功能名；HTML 源码页不再有分段切换条；
- 目录页列表限宽 1100px 居中，文件页铺满并加入 240ms 淡入转场。

## 修复

- 中文裸 URL 在 Unicode 空白/全角句末标点处截断，不再吞掉后续句子；
- 高亮主题切到 VS Code Light+/Dark+，浅色不再出现不可读的深色 token；
- 打包遮罩关闭按钮、下载完成反馈与归档目录岛清单的小问题。
