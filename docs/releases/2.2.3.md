# mdview 2.2.3

**发布日期**：2026-11-02

2.2.3 是一个前端可读性与导航完整性修复版本。服务端行为、路由、Trust/CSP、
文件编码检测、压缩包范围、配置格式与 CLI 参数都不变；浏览器基线仍是
Chromium 86+，运行时零外部请求。

关联：[Issue #34](https://github.com/hpyperry/mdview/issues/34) ·
[PR #35](https://github.com/hpyperry/mdview/pull/35)

## 修复

### 深色导航三角不再发黑

文件导航的目录行原先这样渲染展开箭头：

```tsx
<Icon name="chevron-right" class="nav-chevron" />
```

`Icon` 组件把传入的 `class` 当成完整类名，替换掉了默认的 `icon` 基类。箭头 SVG
因此失去 `fill: none; stroke: currentColor`，退回浏览器默认的 `fill: black;
stroke: none`。浅色主题下看起来只是一个普通的黑色三角，深色主题下就变成一块
几乎看不见的黑块。

修复方式是在组件层保留基类，自定义 class 只叠加：

```tsx
const classes = className ? `icon ${className}` : 'icon';
```

现在深色下箭头的计算样式为 `fill: none`、`stroke: rgb(145, 152, 161)`，与同级
文件夹图标一致；展开时仍旋转 90°。

### 页内目录覆盖全部标题层级

右侧 TOC 原先只查询 `h2`/`h3`，正文里的 `h1` 与 `h4`–`h6` 不会进入刻度或文字
大纲。现在覆盖 `h1`–`h6`，包括正文第一个标题 `h1`；服务端额外输出的 `sr-only`
文件名标题位于 `.markdown-body` 之外，不会重复进入目录。

同时调整了全层级下的表达方式：

- 扁平列表按级别递增缩进：`h3` 20px，之后每级 +12px；
- 刻度宽度随级别递减，`h1` 13px 到 `h6` 3px；
- `h1`–`h6` 都补了 `scroll-margin-top`，跳转不被 sticky 顶栏遮挡。

### 长文档细轨可达

当文档标题数超过视口高度时，TOC 细轨会高于视口。由于细轨使用 sticky，后半段
刻度会被钉在视口下方，滚动正文也无法让它进入视野。

现在 `.toc-ticks` 在视口内限高并独立滚动；scroll-spy 切换当前标题时，会把对应
刻度滚进细轨可视区。`/tests/fixtures/toc-all-levels/root/long.md`（61 个标题）
用于复测这一行为。

### 深色刻度对比度

未选中刻度原先使用 `--border`，深色下是 `#30363d` 压在 `#161b22` 上，几乎不可
见。新增 `--border-strong`：浅色 `#8c959f`、深色 `#6e7a86`，两份深色色板保持
逐项一致；当前项仍使用强调色。

## 复测

人工复测文档：[`tests/fixtures/toc-all-levels/README.md`](../../tests/fixtures/toc-all-levels/README.md)

入口：

```bash
cargo build --release
./target/release/mdview --root tests/fixtures/toc-all-levels/root --trust --port 8005 --port-tries 0
```

重点检查：

1. `/all-levels.md`：7 个标题覆盖 `h1`–`h6`，缩进与刻度宽度逐级变化；
2. 深色主题：未选中刻度可辨，导航三角为描边而不是黑块；
3. `/long.md`：细轨可滚到最后一项，当前刻度自动跟随；
4. `<1360px`：正文顶部内联目录同样包含 7 个条目。

## 兼容性

- CLI、URL、Trust/CSP、编码检测、压缩包范围与配置格式不变；无需迁移。
- 唯一可见行为变化是页内目录条目范围扩大，包含正文第一个 `h1`。
- 交付产物仍为单文件，内嵌 CSS/JS/图片与 highlight.js；运行时零外部请求。
- 浏览器基线 Chromium 86+。

## 已知限制

- TOC 由浏览器运行时生成；禁用 JS 时没有目录。
- 正文第一个 `h1` 按约定进入目录，与正文标题重复是预期行为。
- 细轨只表达标题位置；极长标题在展开的文字大纲里换行显示。
- 目录文本取 `textContent`，标题内的 HTML 标签不会保留。
