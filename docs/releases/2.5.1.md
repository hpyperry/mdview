# mdview 2.5.1

**发布日期**：2026-11-07

2.5.1 修复源码页的铺满与行号栏观感，并让超过 1 MB 的压缩/单行源码恢复语法高亮。
CLI 参数、Trust/CSP 边界、编码检测、压缩包范围与配置格式不变，运行时仍然
零外部请求。

关联：Issue [#77](https://github.com/hpyperry/mdview/issues/77)；PR [#78](https://github.com/hpyperry/mdview/pull/78)。

## 修复：源码页铺满与行号栏

- 短文件的代码背景、行号栏与右边框延伸到主岛底部，不再是一条灰色带 + 空白；
- 行号栏最小宽度 46px，数字使用 `tabular-nums`；
- 长源码仍由 `.content-card` 作为唯一滚动容器。

## 修复：大文件提示与分块

- 只有 >256 KB **且** >500 行才进入分块模式；
- 1 MB/11 行这类文件保持单块，不再显示“文件较大”；
- 分块提示改为“已分块加载完整内容”。

## 修复：大块高亮改用 Worker

- 单块文本 >256K 字符时交给同源 `/_assets/hlworker.js`，3 秒超时；
- 超时或报错时回收 Worker 并回落纯文本，下次请求再重建；
- 小代码块仍在主线程同步高亮；
- Worker 由 `web/build.mjs` 复用 `highlight.min.js` 生成，
  `MDVIEW_WEB_PREBUILT` 发布路径同样包含该资产；
- CSP 仅新增 `worker-src 'self'`，不引入 `blob:`，也不放宽 `script-src`。
