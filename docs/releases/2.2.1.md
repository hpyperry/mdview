# mdview 2.2.1

**发布日期**：2026-10-30

2.2.1 是一个浏览器兼容性修复：把 CSS 收敛到 Chromium 86 基线，修复旧内核
（360 信创版、统信 UOS 内置浏览器等）下品牌块、顶栏、搜索键帽、目录隔线、链接色
与代码块底色静默丢失的问题。没有新增功能，也没有配置或 URL 变化。

## 修复

- **旧内核样式静默失效**：`app.css` 原本用 `light-dark()`（12 处，需 Chromium
  123+）定义全部颜色 token、`color-mix()`（5 处，需 111+）做半透明、`inset: 0`
  （需 87+）定位遮罩。旧内核会把整条声明判为 *invalid at computed-value time*：
  背景透明、边框 `none`、阴影 `none`，但 `backdrop-filter`（76+）仍然生效，于是
  顶栏只剩一层模糊。CSS 无效值不报错，所以控制台与网络面板都没有异常。
- 改为**静态双色板**：`:root` 写浅色，深色在 `@media (prefers-color-scheme: dark)`
  与 `html[data-theme="dark"]` 两处各写一份；半透明层次改用 `--topbar-bg`、
  `--surface-translucent`、`--accent-wash` 与预计算的 `--hover`；`inset` 展开为
  四边。现代浏览器观感不变，顶栏仍是半透明 + 毛玻璃。
- **构建 target 固定为 `chrome86`**：esbuild 压缩会把 `top/right/bottom/left` 重新
  合并成 `inset` 简写，只改源码会在产物里被抵消；固定 target 后不会再回退。

## 改进

- 新增 `tests/check-css-baseline.mjs`：带最低版本注释的特性黑名单（`light-dark()`、
  `color-mix()`、现代颜色函数、`inset` 简写、`:is`/`:where`/`:has`、`@layer`、
  `@container`、CSS 嵌套、动态视口单位、`text-wrap`、`scrollbar-gutter`、`subgrid`、
  `overflow: clip`、`accent-color`、`text-underline-offset`），扫描
  `web/src/styles/` 与 `assets/*.css`；同时逐项比对两份深色色板，防止手写副本漂移。
  已接入 `tests/run-all.sh`。
- 文档：新增 [ADR 0022](../architecture/adr/0022-browser-baseline-chromium-86.md)
  （浏览器兼容基线）、功能矩阵 F-93、
  [`tests/fixtures/chromium-baseline/`](../../tests/fixtures/chromium-baseline/README.md)
  复测文档与旧内核自检页 `probe.html`；README 与 AGENTS 声明 Chromium 86+ 基线。

## 兼容性

- 浏览器要求明确为 **Chromium 86+**。Chrome、Edge、360 信创版、统信 UOS 内置浏览器
  等满足；Chromium 78 及更早不保证（flex `gap` 等仍有差异）。
- 服务端行为、URL 规则、Trust/CSP、配置格式全部不变。
- 现代浏览器上的颜色值逐项等价，仅半透明混色由 `color-mix()` 换成等值静态 rgba。

## 已知限制

- 浏览器探针仍跑最新 headless Chrome，无法自动模拟旧内核；基线靠静态检查 +
  `probe.html` 真机复测。
- 旧内核复测本轮使用 Ubuntu 26.04 arm64 + Chromium 92（Rosetta 转译）验证；统信 UOS +
  360 信创版真机尚未复测，失效机制相同。
