# mdview 2.0.1

**发布日期**：2026-10-21

2.0.1 是 2.0.0 之后的第一个功能版本：HTML 文件按 Trust 分流、压缩包在线预览、
目录行固定列，以及 Linux 上 `_nav` 因权限目录整树 500 的修复。

## 新增

- **HTML 文件 Trust 门控**：已信任根直接以 `text/html` 顶层返回原文，无 mdview
  外壳、无沙箱、无 CSP；脚本、`localStorage`、同源 fetch、下载和顶层链接都像普通
  静态服务器。未信任根才使用外壳 + 沙箱 iframe，脚本处于 opaque origin。
  `?raw=1` 始终源码，`?view=1` 在可信根是原文、未信任根是沙箱裸页。
- **HTML 子资源 MIME**：相对 CSS/JS/JSON 按 `Sec-Fetch-Dest` 返回真实 MIME；
  直接导航仍是源码页。HTML 搜索结果行跳到 `?raw=1#L<n>`。
- **SVG 直开 sandbox**：`image/svg+xml` 加 `CSP: sandbox`，内嵌 `<script>`
  不再同源执行；`<img>` 内嵌不受影响。
- **压缩包预览**：`.zip` / `.tar.gz` / `.tgz` / `.7z` 映射为虚拟目录
  （`/a.zip/docs/x.md`）。包内 Markdown、HTML、源码、图片、下载复用现有管线；
  相对链接与图片保持在包内。整包与条目均可下载。
- **目录行固定列**：图标 / 名称 / 大小 / 修改时间 / 操作五列；HTML 的源码入口
  不再挤动大小/时间列。操作图标有 36×36 点击区和 8px 间距，下载改为图标 +
  悬浮提示，与源码图标一致。
- **`--verbose` 诊断**：请求日志包含方法、路径、`Sec-Fetch-Dest`、状态、
  `Content-Type/Length` 与耗时；启动时打印内嵌资产尺寸；`?open=` 令牌脱敏。

## 修复

- **Linux `_nav` 500**：`/_nav` 递归遇到无权限目录（如 `lost+found`）或条目时
  跳过并返回 `partial: true`，不再整树 500；导航浮岛显示“部分目录无法读取，
  内容未显示”。根目录本身不可读仍返回 500。
- **空 web 资产**：构建时拒绝空的 `app.js` / `app.css`，启动时对空资产 warning，
  避免离线自编译产物静默丢样式。
- **`--max-preview`**：不再误伤预览内的 CSS/JS/图片子资源；直接打开文档仍按上限
  下载。
- **CI**：适配 Rust 1.99 Clippy 的 `result_large_err`，Release/CI 在 4 个目标上
  全绿。
- **触屏**：目录行操作在 `@media (hover: none)` 下常显。

## 行为与安全说明

- HTML 原文只对**已信任根**开放：脚本可读同源数据，这是 Python 版/静态服务器的
  行为，也是 Trust 必须真实的原因。未信任根不提供 raw。
- 压缩包解压到进程私有临时目录（0700），包 200 MB / 解压 1 GB / 2 万条 /
  单条 100 MB 上限；拒绝加密、多卷、绝对路径、`..`、软链/硬链、设备文件、
  重复路径。嵌套包不递归；`--safe` 下压缩包不可见。
- 包内 HTML 跟随服务根 Trust：trusted 原文，untrusted 沙箱。
