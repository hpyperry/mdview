# ADR 0032：页面身份与操作迁入全局顶栏

- Status: accepted
- Date: 2026-11-07
- Supersedes: [ADR 0031](0031-fixed-page-head-island.md)

## 背景

ADR 0031 把页头固定在主岛顶部。实际使用后，用户选择更进一步：把页面身份和操作
全部迁到全局顶栏，正文直接从主岛顶部开始，最大化阅读空间。

## 决策

### 1. 顶栏承担页面上下文

文档、源码、目录页的顶栏从左到右：

1. 全站导航按钮；
2. 面包屑路径（不包含当前文件名）；
3. 居中的文件名与第二行元信息（类型/大小/编码/更新时间）；
4. 点状「页面操作」菜单（源码/下载/导出图片/导出 PDF，按页面类型出现）；
5. 搜索；
6. 主题。

- 去掉产品 logo；导航按钮和面包屑承担首页/路径入口；
- 文件名 22px 加粗，元信息 11px 第二行，建立主次；
- 操作菜单按钮与搜索/主题一样是 `icon-btn`，默认无边框/无底色，`title` 提供
  “页面操作（源码 / 下载 / 导出）”提示；点击展开 142px 二级菜单；
- 顶栏岛、主岛、TOC 岛之间的间距统一为 `--island-gap: 24px`；
- 宽屏顶栏 64px，≤1280px 隐藏元信息并回到 56px；≤900px 隐藏面包屑，文件名 16px。

### 2. 服务端直接输出

- `PageHead::render_topbar()` 复用 crumbs/title/meta/actions，生成
  `.topbar-path` / `.topbar-context` / `.topbar-page-actions`；
- `Page.topbar` 传给 `html_page`，文档、源码、目录页不再在 content card 内渲染
  `.page-head`；
- 不使用运行时 JS 搬 DOM，避免首屏布局抖动；
- `.page-head` 只保留给搜索页（搜索表单仍需要独立页头）；
- 信任/错误页没有页面上下文，顶栏只保留导航/搜索/主题。

### 3. 交互与滚动

- 新 `actions` 岛负责菜单开合、Esc/外部点击关闭、`aria-expanded`；
- 导出图片后菜单保持打开以显示完成图标；下载在反馈窗口结束后关闭；
- 页面仍使用固定主岛 + 岛内滚动；TOC 跳转、行定位和源码锚点不再需要避让
  content 内页头（搜索页仍保留自己的页头）。

## 后果

- 正文多出原来页头约 129px 的可视高度；
- 页面操作始终可达，且不会和长文档阅读冲突；
- 顶栏信息密度上升，依赖 1280/900 的渐进隐藏；
- 搜索页是唯一保留 content 页头的页面，因为表单不适合塞进顶栏。
