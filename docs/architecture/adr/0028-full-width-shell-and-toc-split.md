# ADR 0028：内容岛铺满外壳，Markdown 分栏只收右边缘

- Status: accepted；其中“1680px 外壳上限 / 分栏只收右边缘”由 [0036](0036-wide-content-group.md) 取代
- Date: 2026-11-06

## 背景

ADR 0026 把宽屏正文岛固定在 1240px，并把 TOC 岛放在右侧。实际使用中，低于
1080p 的屏幕（1366×768、1440×900 等）会出现两个问题：

- 内容岛居中且最大 1240px，左右留白过多，和铺满的顶栏不对齐；
- Markdown 页进入时右列突然出现，内容岛/正文宽度发生跳变，看起来像整页被压缩。

用户要求：主岛在只有内容时铺满屏幕，边缘与顶栏对齐；进入 Markdown 预览时主岛
平滑分裂成“正文岛 + 右侧目录岛”，但正文行宽不变，只收主岛右侧空边。

## 决定

### 1. 内容岛铺满 `.app`

- `.content-card` 不再设置居中 `max-width`，宽度为 100%；
- 所有页面类型（Markdown、源码、目录、搜索、压缩包、信任/错误面板）都使用同一
  外壳宽度；
- `.app` 仍是 1680px 上限 + 16px 外边距，顶栏和主岛共享左右边缘。

### 2. 阅读行固定、左对齐

- `--read-width` 使用
  `min(1200px, calc(100vw - var(--toc-island-width) - 108px))`；
- `.markdown-body` / `.toc-inline` 使用 `margin: 0`，内容从主岛左侧 30px 开始，
  不随主岛右边缘收缩而重新居中；
- 这样分栏前主岛右侧空边被目录岛占据，正文的 `x` 坐标和行宽都不变。

### 3. 断点与宽度

- **≥1280px**：`grid-template-columns: minmax(0, 1fr) clamp(160px, 13vw, 240px)`，
  间距 16px；正文岛只收右边缘。
- **1100–1279px**：保留 24px TOC 细轨，悬停刻度显示单条标题，按钮展开大纲。
- **<1100px**：单列，TOC 回到正文顶部内联块。
- TOC 岛宽度上限 260px，避免在 1680px 外壳上无限拉宽。

### 4. 挂载动画

- 服务端只输出空的 `.toc-rail`；浏览器挂载 TOC 后设置
  `body[data-has-toc="1"]`；
- CSS 在该属性出现时播放 `shell-split`（`grid-template-columns` 从
  `1fr 0px` 到 `1fr var(--toc-island-width)`，240ms）和
  `toc-island-in`（淡入 + 右移 14px）；
- 动画未生效的旧内核直接落到最终分栏，不阻塞内容；
- `prefers-reduced-motion: reduce` 下禁用动画。

### 5. 源码页只保留预览

- 源码页页头不再提供下载按钮；下载仍可直接请求 `?download=1`；
- Markdown 源码页保留“预览”，HTML 源码页保留“预览/源码”分段；
- 目录列表的下载图标、文档页的下载按钮不受影响。

## 备选方案

- **保持 1240 居中，只把 TOC 岛叠加在右侧**：会遮住正文或让目录浮层化，不符合
  “两个岛”的体验。
- **用 `transform: scale()` 缩小主岛**：正文会模糊、命中区域偏移，且行宽实际变化。
- **给主岛加 `max-width` 过渡**：内容仍会重新居中/回流，无法做到正文不动。

## 后果

- 低分辨率屏幕内容区明显变宽，主岛与顶栏对齐；
- Markdown 分栏时正文不移动、不回流，只动画收起右侧空边；
- 旧内核没有 grid 过渡时直接分栏，功能不受影响；
- 源码页操作更聚焦；需要下载时仍可通过 URL 直接请求；
- F-29/F-35/F-45/F-50/F-51/F-52 的验收口径同步更新。
