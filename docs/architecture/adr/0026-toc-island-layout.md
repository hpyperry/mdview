# 右侧 TOC：常驻目录岛 + 折叠细轨

**Status**: accepted（2026-11-06）。取代旧的“24px 鱼骨细轨 + 悬停整块面板”作为
宽屏唯一形态；F-50/F-51/F-52 的验收口径随之更新。

## 背景

旧设计在 ≥1360px 放一条 24px 细轨：

- 每个刻度只有一条短横线，悬停整个细轨会展开完整文字大纲；
- 悬停某个刻度无法知道“这一条具体是什么标题”，只能看完整面板；
- 悬停展开和左上角导航按钮的体验几乎一样，细轨没有独立的导航价值；
- 返回顶部按钮固定在右下角，标题很多时与细轨/刻度重叠；
- 如果为了显示文字大纲而直接加宽右列，正文会被压缩，和“正文宽度不因目录变化”
  的目标冲突。

用户要求：正文主体宽度保持不变；宽度够时正文岛左移，右侧出现独立的常驻目录岛；
宽度不够时目录岛折叠成隐藏式；返回顶部不能和目录重叠。

## 决定

### 1. 两个独立的岛

Markdown 文档页在宽屏下是：

```text
[ 正文岛 1240px ]  24px  [ 目录岛 ≥220px ]
```

- 正文岛宽度固定为 `--card-width`（1240px），不因目录出现而缩小；
- 目录岛最小宽度 `--toc-island-width`（220px），宽屏按剩余宽度伸展；
- 两个岛之间有 24px 间距；两岛整体与顶栏共用 `.app` 的 16px 外缘 padding，不再额外居中留大边；
- 目录岛是独立卡片（边框、圆角、背景、阴影），不是正文的一部分。

### 2. 断点

| 宽度 | 形态 |
|---|---|
| ≥ 1560px | 正文 1240 + 间距 24 + 常驻目录岛（≥220，按剩余宽度伸展）；两岛外缘与顶栏同 padding |
| 1360–1559px | 24px 细轨；悬停刻度显示该标题的浮层；点击顶部按钮展开完整大纲 |
| < 1360px | 正文顶部内联目录（现状） |

1560 的依据：1240 + 24 + 220（目录岛最小宽度）+ 32（`.app` 左右 16）+ 约 15（滚动条）
≈ 1531，留出余量。窗口小于该值时目录折叠，而不是压缩正文。

### 3. 交互

- 常驻目录岛直接列出所有标题文字，当前项高亮；列表独立滚动，当前项自动进入视野；
- 目录岛底部有“回到顶部”，不再使用固定右下角的全局回顶按钮；
- 细轨模式：悬停/聚焦某个刻度只显示**这一条标题**的浮层；完整大纲只在点击顶部
  按钮时展开，不再因为鼠标经过细轨而自动展开；
- 细轨模式的全局回顶按钮右移 46px（`--toc-rail + 22px`），与细轨错开；
- 无标题文档不显示目录岛/细轨，正文恢复单列。

### 4. 跳转

TOC 点击不再依赖 `scrollIntoView({behavior:'smooth'})`：

```ts
const offset = topbarHeight + 32;
window.scrollTo({ top: scrollY + target.top - offset, behavior: 'auto' });
```

嵌入/旧 Chromium 里 smooth scroll 会停住或完全忽略；TOC 是导航，不是装饰，
所以用即时跳转。标题顶部固定落在 sticky 顶栏下方约 88px。返回顶部沿用同一
偏移思路。

## 考虑过的替代方案

- **保留鱼骨 + 只加 `title`**：原生 tooltip 慢且不稳定；不能解决“不知道光标旁
  是哪一节”的问题。
- **≥1360px 直接显示 220px 文字面板**：正文会被压缩到 1240 以下，违背“正文宽度
  不变”；在 1440 屏上尤其明显。
- **目录岛浮层覆盖正文**：不压缩正文，但会遮挡阅读；宽屏下不如常驻岛。
- **完全去掉细轨，只留按钮**：干净，但失去“扫一眼全文结构”的能力；保留为窄屏
  内联目录的补充。
- **保留悬停整块面板**：与导航按钮重复；用户明确反馈无法辨认具体刻度。

## 后果

- ≥1560px 的文档页右侧有稳定的文字大纲，正文宽度不变；
- 1360–1559px 仍是紧凑细轨，但悬停能读到单条标题，完整大纲需点击；
- 返回顶部不再覆盖目录；常驻模式在目录岛内，细轨模式右移；
- 小于 1560px 没有常驻目录岛；这是有意的空间取舍；
- TOC 跳转为即时滚动，不再有平滑动画；换取各浏览器一致可用。
