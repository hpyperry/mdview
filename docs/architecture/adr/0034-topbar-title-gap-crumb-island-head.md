# 顶栏文件名、缝隙面包屑与主岛功能区

**Status**: accepted（2026-11-07）
**Supersedes**: [0033](0033-clean-topbar-page-head.md) 的布局部分

## 背景

0033 把页面身份与操作放在内容区顶部的页头岛，面包屑在页头内、文件信息在顶栏与
主岛之间的缝隙。实际使用中，滚动后文件名、面包屑、文件信息分散在三处；窄屏时
缝隙里的文件信息只能整页横向滚动，或者把页面撑宽。

## 决定

1. **顶栏只保留三件事**：最左导航、居中的文件名、右侧全局搜索/主题。文件名过长
   省略，不挤压两侧控件；顶栏不再放页面操作。
2. **面包屑放进缝隙**：位于顶栏与主岛之间，左对齐，与上下两个岛左右对齐；面包屑
   换行时缝隙自然增高，不再给缝隙做横向滚动。
3. **文件信息与操作固定在主岛顶部**：一条 sticky 栏，左侧操作、右侧文件信息。
   Markdown 的源码/下载/导出图片/导出 PDF、源码页的预览/下载、压缩包目录的
   下载压缩包都在这里；顺序固定为「搜索 复制 下载 其余」。
4. **操作默认只显示图标**：hover/聚焦浮出功能名，统一使用即时 `data-tip` 浮层，
   不再叠加延迟的原生 `title`。
5. **窄屏两级收敛**：先保留左侧操作、把整排收进「更多」；仍放不下时隐藏右侧
   文件信息。主岛顶部栏始终单行。
6. **文件页工具**：搜索打开内容区右上浮层（匹配计数、上一个/下一个、Esc），
   复制通过 `?download=1` 取回原始全文；两者只在文档页和源码页出现。
7. **目录页**：列表限制在 1100px 居中列，文件预览页恢复铺满并做 240ms 淡入；
   目录行操作常驻，固定两个槽位，超出收进行内「更多」。

## 后果

- 顶栏、缝隙、主岛三层的职责固定：外壳控制 / 路径 / 文件身份与操作。
- 页头 `PageHead` 仍用于搜索页和错误/信任页；文档、源码、目录不再渲染内容页头。
- 面包屑与文件信息的位置互换后，`toc.tsx` 的 sticky 偏移改为测量
  `.island-head`；搜索页的页头平铺。
- 文件夹打包下载只在可信根开启，`--safe` 与未信任根拒绝，避免绕过 Trust。
