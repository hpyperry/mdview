# 全站导航浮岛：默认收起、空闲预取、只导航文件

**Status**: accepted（2026-10-20）；同日修订：首次打开懒加载改为页面空闲预取
（用户选择只做空闲预取，不跨页缓存、不做服务端 TTL）。取代 ADR 0012 中
“左侧当前目录侧栏 + 正文预留导航列”的部分

用户反馈左侧导航应和中间内容解耦，默认收起；中间的正文是核心岛；左右两侧和
中间目录页不再显示“目录/文件”分组文字。当前侧栏只看当前目录，展开时用
grid 列挤压正文；默认展开，和“核心岛”目标冲突。

## 决定

1. **全站树**：导航从根目录开始，包含所有可见目录与文件（图片/PDF/二进制
   也显示）；目录在前、文件在后，按名称排序。隐藏目录与 `SKIP_DIRS` 仍跳过。
2. **默认收起、每次加载收起**：打开状态不持久化。展开状态（哪些目录打开）
   存 localStorage，并与当前路径的祖先合并。
3. **空闲预取**：页面加载后由导航岛在浏览器空闲时请求 `GET /_nav`；返回 JSON
   树，由 Preact 导航岛渲染。首次打开通常已就绪；打开时若预取未完成，仍显示
   “加载中…”并复用同一请求。树不内嵌进 HTML，也不跨页缓存；服务端保持实时
   扫描，不引入 TTL 缓存。CSP 使用 `connect-src 'self'`。
4. **浮层不占布局**：桌面是左上角悬浮面板（默认无遮罩，点外部/Esc 关闭）；
   ≤900px 为全高抽屉 + 遮罩。正文宽度始终不变（核心岛）。
5. **点击分工**：目录行只展开/收起，不进入目录页；文件行才导航。当前文件
   高亮，当前路径自动展开。
6. **头部**：浮岛顶部显示根目录名和关闭按钮；不显示“当前目录/文件/目录”等
   分组文字。
7. **目录页统一列表**：中间目录页不再分“目录/文件”两段，改为一张统一列表
   （目录在前、文件在后），仍用图标和排序区分。根目录面包屑不再显示“目录”。

## 考虑过的替代方案

- **每页服务端内嵌整棵树**：无新接口、无 CSP 变更，但默认收起时每页仍携带
  全站树，大仓库成本高。
- **只展开当前路径**：实现简单，但用户探索其他目录后切换页面会丢失展开状态。
- **所有尺寸都抽屉/都浮岛**：桌面全高抽屉过重；移动端浮岛会遮挡过多内容且
  关闭不如遮罩抽屉直观。
- **目录行点击进目录页**：与“导航只定位文件”冲突，且目录展开与导航两个动作
  会争夺同一次点击。
- **跨页缓存 + 服务端 TTL**：sessionStorage 缓存 + 空闲预取 + 服务端短 TTL
  能让后续页面也零等待，但需要失效策略与缓存一致性测试；当前文档库规模下
  只做空闲预取已足够，保留为后续优化。

## 后果

- 新增 `/_nav` 接口与 `connect-src 'self'`；导航树在页面空闲时预取，首次打开
  通常已就绪，但预取完成前打开仍可能看到“加载中…”。
- 默认收起后，正文在 901–1359px 也不再被导航列挤压；此前该区间的“正文
  被压到约 620px”问题消失。
- 无 JS 时没有导航入口；目录页、面包屑与搜索仍可完成基本导航。
- 目录页的分组标题与左侧树的“文件/目录”小标题消失；排序与图标承担区分。
- 浏览器验收新增导航默认关闭、空闲预取、不挤压正文、目录只展开、文件导航、
  展开记忆、移动抽屉/遮罩、无 JS 隐藏等断言。
