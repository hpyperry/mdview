# ADR 0036：超宽屏外壳铺满，进入 Markdown 时主岛让出目录岛宽度

- Status: accepted
- Date: 2026-11-11

## 背景

ADR 0028 把内容岛从 1240px 居中改成铺满 `.app`，但保留了 `.app` 的 1680px 上限
和正文 1200px 的阅读行宽。在 1680px 以下的屏幕上这段关系成立：主岛铺满外壳，
Markdown 页只把右侧空边让给 TOC 岛。

在 2560px（2K 屏、4K 屏 150% 缩放、或 80% 浏览器缩放）上，`.app` 固定 1680px，
两侧各留下 440px 空白，顶栏和主岛看起来像一块居中的浮层。实测
（2560×1440，`docs/manual/README.md`）：外壳 1680px，主岛 1376px，正文 1200px，
两侧空白各 440px。用户反馈“整体布局没有撑满”。

修复过程中试过两种布局，都被否决：

1. **主岛拉满、TOC 岛绝对定位**：TOC 画在主岛表面上，两个面板不再分开；
2. **主岛收窄、主岛与 TOC 作为一组居中**：页面左右各留 528px 空白，看起来仍是
   “居中”的浮层。

最终方案保持 2.5.x 的“主岛铺满、右边缘让位”逻辑，只去掉 1680px 上限。

## 决定

### 1. 外壳不再设最大宽度

- 删除 `--app-width: 1680px`，`.app` 只保留 16px 外边距；
- 顶栏在所有页面类型上都铺满视口；
- 目录页列表仍限宽 1100px 居中，信任/错误面板等自带上限的块不变。

### 2. ≥1280px：主岛左边缘不动，右边缘让出目录岛

- Markdown 页的 `.shell` 使用两列：`minmax(0, 1fr)` + `var(--toc-island-width)`
  （`clamp(160px, 13vw, 240px)`），列间距 32px；
- 主岛左边缘始终贴 `.app` 左侧（16px），进入 Markdown 页后右边缘只向左缩进
  “目录岛宽度 + 32px”（2560px 下为 272px）；
- 目录岛是两个独立面板中的第二个，右边缘与顶栏右边缘对齐，页面最右侧仍保留
  16px 外边距；主岛与目录岛之间露出 32px 页面底色；
- 正文在主岛内水平居中（左右自动外边距），最大 1200px；主岛、面包屑、工具栏和
  TOC 岛的位置不因正文居中而移动；主岛右侧多出来的宽度是文档画布，不再堆到正文
  与目录之间；
- 无标题文档（`.no-toc`）恢复单列，主岛重新铺满；
- 面包屑与主岛左边缘对齐；搜索页页头与结果限宽到
  `--read-width + 32px + 目录岛宽度` 并居中，避免结果行横贯整屏。

### 3. 动画

- 两列轨道从首帧就存在，不依赖 JS 挂载，因此打开文档时不会发生宽度跳变；
- 取消 `shell-split` 网格动画；TOC 岛挂载时只播放 `toc-island-in` 淡入 + 右移
  14px，约 240ms；
- `prefers-reduced-motion: reduce` 下禁用。

### 4. 断点不变

- **1100–1279px**：仍是 24px 目录细轨，悬停显示单条标题，点击按钮展开大纲；
- **<1100px**：单列，目录回到正文顶部内联块；
- **≤900px**：移动布局，普通文档滚动。

## 备选方案

- **主岛铺满、TOC 岛绝对定位在主岛右侧**：外壳最“满”，但 TOC 会画在主岛表面上，
  两个面板不再分开。
- **主岛收窄、与 TOC 作为一组居中**：两个面板分开了，但超宽屏左右各留 500px 左右
  空白，仍然像居中的浮层。
- **只把 `--app-width` 提到 2080/2400px**：改动最小，但 2560px 屏上仍有单侧留白。
- **正文跟着主岛拉长**（例如 1500–1700px）：能填满主岛，但 2K 屏上单行超过
  1500px，阅读视线跨度过大；本轮明确保持 1200px 阅读行。

## 后果

- 超宽屏不再有 1680px 的灰色外框，顶栏与主岛铺满视口；
- 进入 Markdown 页时只收主岛右边缘，正文在主岛内居中；主岛与目录岛之间有 32px
  页面底色，两个面板独立；
- 主岛左边缘、面包屑、工具栏操作保持不动；2K 下正文左右各留 528px，视觉不再
  贴左；
- 主岛右侧的大块空白是文档画布的一部分，而不是外壳之外的灰边；如果以后要利用
  这部分宽度，应单独调整 `--read-width`，不要重新引入居中布局；
- 浏览器探针新增“主岛左侧与顶栏对齐”“目录岛与顶栏右对齐”“主岛为目录岛让出
  32px”“正文在主岛内居中”“2560 正文仍为 1200px”的断言；
- F-50 的验收口径同步更新，ADR 0028 中“1680px 上限”的部分由本决策取代。
