# ADR 0031：文档页头固定为独立页头岛

- Status: accepted
- Date: 2026-11-07

## 背景

主岛固定后，正文在岛内滚动，但页头仍随内容滚出可视区。页头承担源码、下载、
导出图片、导出 PDF 等高频操作；读到文档中段后要回到顶部才能切换，成本高。

原型比较了三种方案：A 页头随内容滚动、B 页头贴住主岛顶部、C 页头作为独立悬浮岛。
用户选择 C。

## 决策

- **≥901px**：
  - `.page-head` 在 `.content-card` 内 `position: sticky; top: 12px`；
  - 外边距 `12px 14px 0`，圆角 `--radius-lg`，1px 边框与浮层阴影；
  - 背景使用不透明 `var(--surface)`，正文从页头下方滚过；
  - 页头与主岛左右边缘保持 14px 内缩，形成独立岛视觉；
  - 滚动时顶栏、页头岛、主岛外框、TOC 岛都不动，只有正文滚动。
- **≤900px**：不启用 sticky 页头，保留普通文档流与页面滚动。
- 滚动定位避让：
  - TOC 跳转与 scroll-spy 读取 `.page-head` 的 `height + top + 24`；
  - Markdown 行定位、源码锚点使用 `scroll-margin-top: 180px`；
  - 页头高度变化（长文件名换行）由运行时计算覆盖 TOC 跳转。
- 页头岛在打印时仍隐藏，保持已有打印样式。

## 备选方案

- **A 保持滚动**：操作需要回顶部，用户已否决。
- **B 贴住主岛顶部**：视觉更克制，但不是用户要的“独立岛”。
- **把页头拆成独立 DOM 卡片**：需要重排 `.content-card` 与正文滚动容器，收益只是
  少一层嵌套；当前 sticky 方案已能达到独立岛视觉，风险更小。

## 后果

- 阅读中段仍可直接使用源码/下载/导出；
- 页头占约 129px 高度，正文可视高度减少；12px 顶部间距与阴影增加视觉层次；
- 所有锚点定位必须避开页头，不能再假设内容从卡片顶部开始；
- 移动端保持原布局。
