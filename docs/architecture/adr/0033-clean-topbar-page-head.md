# ADR 0033：顶栏只保留外壳控制，页面身份回到底部页头岛

- Status: accepted
- Date: 2026-11-07
- Supersedes: [ADR 0032](0032-topbar-page-context.md)

## 背景

ADR 0032 把面包屑、文件名、元信息和页面操作全部塞进顶栏。实际使用暴露了两个问题：

- 面包屑一长就伸到中间，覆盖居中的文件名与元信息；
- 顶栏同时承担全站导航、页面身份、页面操作、搜索和主题，1366/1280 下信息
  堆叠严重；源码页没有操作菜单时，搜索/主题还会被挤到中间。

用户要求顶栏保持干净：只保留最左侧的全站导航、右侧搜索和主题。页面身份与操作
应回到内容区，再逐步讨论信息层级。

## 决策

### 1. 顶栏只保留外壳控制

固定为三项：

```text
[导航]                                      [搜索] [主题]
```

- 不再放 logo、面包屑、文件名、元信息或页面操作；
- 顶栏高度回到 56px（移动端 52px），`topbar-actions` 始终右对齐；
- 不再需要 `actions` 岛；移除其 manifest、注册与文件。

### 2. 页面身份回到内容区的页头岛

Markdown、源码、目录、搜索重新统一使用服务端 `PageHead`：

- 页头在 `.content-card` 内，≥901px 为 sticky 岛（top 12、左右 14 内缩、圆角/
  阴影）；
- 面包屑、文件名/标题、元信息与操作都在页头内，长路径在页头内换行，不再与
  文件名抢同一行；
- 操作按钮直接显示（源码/下载/导出图片/导出 PDF、预览、下载压缩包等），不再收
  二级菜单；
- 搜索页继续使用自己的页头与表单；
- 顶栏、主岛、TOC 岛间距保持 24px。

### 3. 滚动与锚点

- 主岛仍是唯一滚动容器；页头 sticky 在岛内顶部；
- TOC 跳转、scroll-spy、行定位与源码锚点继续避让 sticky 页头；
- 横向双指滑动仍可前进/后退。

## 后果

- 顶栏干净，不再因长面包屑覆盖页面信息；
- 所有页面拥有一致的页头结构和操作位置；
- 失去顶栏的 129px 空间收益，但换回可读性和一致性；
- 页面操作重新常驻页头，源码/目录/搜索也不会有“搜索/主题跑到中间”的问题。
