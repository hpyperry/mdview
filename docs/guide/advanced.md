# 边界与约定（示例）

这篇文档专门列出**容易踩的边界**，方便你判断渲染结果是不是预期。

## 会被渲染的

| 写法 | 结果 |
|------|------|
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `***粗斜***` | ***粗斜*** |
| `~~删除~~` | ~~删除~~ |
| `中文*强调*中文` | 中文*强调*中文 |
| `___粗斜___` | ___粗斜___ |

## 刻意不渲染的（按原文输出）

| 写法 | 为什么 |
|------|--------|
| `2*3*4` | 两侧是 ASCII 数字，属「词内」定界符 |
| `a*b` | 同上，避免把变量名里的星号变成斜体 |
| `a__b__c` | 词内下划线同理 |
| `**a*` | 强度不匹配：`**` 不能被单个 `*` 关闭 |
| `\*转义\*` | 反斜杠转义优先于强调 |
| `<script>` | 裸 HTML 一律转义，杜绝 XSS |

## 已知的近似（不是 bug，是取舍）

1. **`---` 只当分隔线，不当 Setext 二级标题下划线。**
   真实文档里「段落 + `---`」几乎总是想要分隔线；`===` 仍然是一级标题下划线。
2. **三连定界符走预处理**：`***x***` 直接产出 `<strong><em>x</em></strong>`。
   像 `***a** b*` 这种 2/1 混排的极端写法不会按 CommonMark 完全还原。
3. **裸 HTML 不透传**，所以 `<br>`、`<details>`、`<div align>` 会显示成文本。
   需要换行请在段末留一个空行。

## 中文与标点

句末标点后仍能正常闭合：

- 这是*斜体*。
- 这是**粗体**！
- 这是~~删除~~？

## 大文件

渲染不限制文件大小；非 UTF-8 内容按 `errors="replace"` 解码，不会 500。
如果目录里混进巨大的 `.md`，用 `--safe` 之外的场景请自行留意内存（渲染结果有 512 项 LRU 上限）。
