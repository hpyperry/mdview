# 边界与约定

这篇文档列出新实现（Rust + comrak）**容易踩的边界**，方便判断渲染结果是不是预期。
总原则：核心语义与视觉对齐 VS Code 1.142；linkify / reference definition /
front matter / URL 与 alt 的硬边角采用 comrak 行为
（[ADR 0005](../adr/0005-vscode-1.142-as-oracle.md)、
[ADR 0007](../adr/0007-hard-edge-cases-use-comrak.md)）。

## 会渲染的

| 写法 | 结果 |
|------|------|
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `***粗斜***` | ***粗斜*** |
| `~~删除~~` | ~~删除~~（输出 `<s>`，不是 `<del>`） |
| `2*3*4` | 2*3*4（`*` 允许词内强调） |
| `中文*强调*中文` | 中文*强调*中文 |
| `` `行内**代码**` `` | 行内码保护内部语法 |
| 四空格缩进 | 缩进式代码块（CommonMark 支持） |

## 刻意不生成 / 不支持的

| 写法 | 行为 | 原因 |
|------|------|------|
| `# 标题` | 不生成 `id` 锚点 | VS Code 核心语义；站内跳转用显式链接 |
| `- [x] 任务` | 字面 `[x]`，无 checkbox | VS Code 预览默认不开 task list |
| `\*转义\*` | 去掉反斜杠、按字面显示 | CommonMark；不再有 `.esc` 装饰 |
| `<script>` | **原样透传** | ADR 0006：Trust + CSP 约束，不再转义 |
| `===` / `---` 下划线 | 都是 Setext 标题 | CommonMark/VS Code；`---` 单独一行才是分隔线 |
| 脚注 / 数学公式 | 不渲染 | comrak 的 footnote/math 扩展关闭 |
| 标题自动编号 / 目录 | 不生成 | 不在范围内 |

## 裸 HTML 与安全

- 裸 HTML 块与行内标签**原样输出**；不执行脚本由 CSP（`script-src 'nonce-…'`）
  和 Trust 拦截页共同保证。
- 未信任目录：每次打开 `.md` 出现确认页 → 一次性令牌（60 秒、路径绑定、消费一次）。
- `?raw=1`（源码视图）与 `?download=1`（原始字节）绕过拦截。

## 链接与图片

- 协议白名单：拒绝 `javascript:`、`vbscript:`、`file:`、非法 `data:` 与
  `vscode:` / `vscode-insiders:`（本服务器无处理器）。
- `data:image/*;…` 在**链接与图片位置都放行**（VS Code 1.142 的 `validateLink`
  覆盖逻辑）；非图片 `data:` 一律拒绝。
- 相对目标：切 `?`/`#` → **解码两次** → 相对解析 → 编码一次 → 根相对 URL。
  文件名里字面含 `%xx` 的文件因此无法通过相对目标到达（accepted deviation）。
- 图片不在链接里时包一层 `<a class="zoom" href="原图">`；徽章写法不嵌套。

## linkify（comrak 行为）

与 VS Code 的已知差异，均已接受：

1. `www.example.com` 会被补成 `http://` 链接；
2. 裸邮箱成为 `mailto:`；
3. 全角句号会被算进 URL（`https://e.com/a。结束` 整段成为链接）；
4. `https://e.com/a&copy;` 会在 `&` 前截断，`©` 留在链接外；
5. 尾部 `:` 归句子。

半角句末标点、括号配平、查询串只转义一次、行内码/围栏内不链接化这些行为与
VS Code 一致。

## 引用定义（comrak 行为）

- 被拒协议的整条定义会被移除，引用退化为字面文本；
- `[pic]: <a b.png>` 这种尖括号定义在文件末尾**没有换行**时可能解析失败，留下字面/畸形 raw HTML；正常文件以换行结尾时能解析；
- 重复定义取第一条；title 与多行定义跟随 comrak。

## front matter

`---` 开头的合法 front matter 块会被**消费**（不显示成表格）；空的
`---\n---` 不视为 front matter，会输出两个分隔线。

## 中文与标点

- `*` 强调在 CJK 旁正常成立；
- `_` 强调不适用于词内（`中文__粗__中文` 保持原样，与 CommonMark 一致）；
- 段内换行按空格连接；需要硬换行请在行末写两个空格或 `\`。

## 大文件

超过 `--max-preview`（默认 20 MiB）的文件改为下载，对 `.md`、图片、源码一律生效，
`?raw=1` 也不能绕过。未超限的非 UTF-8 内容按 UTF-8 lossy 解码，不会 500。

超过 256 KB 的文本源码页仍会输出全文，但按 500 行分块，由浏览器的
`content-visibility: auto` 跳过离屏块的布局与绘制；滚动到附近时才补充行号锚点
并做语法高亮。禁用 JS 时全文仍可读，但没有精确行号深链与懒高亮。
